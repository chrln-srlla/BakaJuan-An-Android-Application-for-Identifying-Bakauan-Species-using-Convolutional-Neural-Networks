# Bakajuan

## Overview

Bakajuan is a mobile application designed to help users explore, manage, and learn about mangrove species. The system allows admins to upload mangrove information with images, while users can browse the mangrove catalog and view detailed information.

---

# Features

* User authentication using Firebase Authentication
* Admin account management
* Add, edit, and delete mangrove data
* Upload mangrove images
* Display mangrove catalog with images
* Search and browse mangrove species
* Responsive Android interface
* Backend API integration using Node.js and MySQL

---

# System Architecture

The application consists of:

1. Android mobile application for users and admins
2. Node.js backend API for handling requests
3. MySQL database for storing mangrove information
4. Firebase Authentication for account management
